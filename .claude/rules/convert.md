# Конвертация в GIF

Любой источник → GIF стикера: кадры, выбор стороны, кодировщик, Worker и фолбэк.

Только GIF amo не перекодирует (PNG и WebP → JPEG с белым фоном), поэтому всё — GIF с 1-битной прозрачностью, потоково:
в памяти ≤ 2 несжатых кадра в очереди Worker-а плюс кадр на холсте.

- **Источник** (`openFrameSource`) — вписан в 512 px, мелкий не увеличивается. Картинки — `ImageDecoder` (план —
  декодированием кадров с немедленным `close`), фолбэк `createImageBitmap`; видео — seek одного `<video>`; `.tgs` —
  Lottie на своём холсте. Источник общий для проходов; `dispose` при любом исходе, у видео — снять `src`, `load()`,
  отозвать blob URL, иначе декодер и файл живут до выгрузки страницы.
- **Анимация** — ≤ 100 кадров и 4 с, 25 fps (40 мс — ровно 4 сотых, задержка GIF в сотых); у анимированной картинки —
  свои задержки, кадр за 4 с урезается (не ниже 20 мс).
- **Сторона** (`sidePick.ts`, `encodeLadder.ts`) — ряд: сторона источника, затем меньшие из 384 / 320 / 256. Если
  кадров больше 8 (`SAMPLE_FRAMES`) и сторона больше 256 — проба из 8 кадров в размере источника, вес масштабируется на
  план и площадь с запасом `SAFETY`, старт — наибольшая сторона с оценкой ≤ 2 МБ (`MAX_GIF_BYTES`, одна на весь код).
  Тяжелее лимита — новый проход следующей стороной, последняя отдаётся как есть. Подпись — на холсте прохода, и в пробе:
  текст не мылится от даунскейла.
- **Кодировщик** (`gifEncoder.ts`, без DOM) — сжатие кадра сразу при записи; палитра rgb565 по непрозрачным пикселям,
  прозрачность — отдельный индекс; Байер 4×4 — только при средней ошибке выше порога, узор по координатам не мерцает.
- **Worker** (`createFrameSink`, свой на проход, из blob URL) — кадр transfer-ом, окно 2 кадра без `ack`. `byteLength`
  отстаёт на кадры в полёте — проба читает вес после `flush`. `close` гасит Worker с памятью кодировщика.
- **Фолбэк** (`frameSinkMain.ts`) — главный поток с уступкой после кадра, только если Worker не дал первый `ack` (CSP,
  конструктор): первый кадр шлётся копией и повторяется, `console.warn`, и `createFallbackAwareSink` до перезагрузки
  Worker не пробует. Сбой после первого `ack` — ошибка конвертации, без перекодирования. В скрытой вкладке фолбэк
  медленный: `setTimeout` тормозится, через 5 мин intensive throttling — раз в минуту.
- GIF без подписи и ≤ 2 МБ — как есть.
