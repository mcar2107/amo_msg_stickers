# Обновление

Как обновлять amo stickers, зависит от способа установки.

## Расширение из Chrome Web Store

Браузер обновляет расширение из магазина сам — ничего делать не нужно. Новая версия попадает в магазин после проверки,
поэтому иногда приходит позже, чем архив и userscript.

Если сейчас у вас расширение из архива, его можно заменить расширением из магазина: удалите расширение из архива
и поставьте его
из [Chrome Web Store](https://chromewebstore.google.com/detail/amo-stickers/abjnjphijggkkdbbmkldhibgepgdcgip).
Ключи GIF и свой токен бота придётся ввести заново, стикеры и паки останутся.

## Расширение из архива {#archive}

Архив сам не обновляется: браузер не знает, откуда брать новую версию.

1. Скачайте новый архив по той же ссылке:
   [amo-stickers.zip](https://github.com/mcar2107/amo_msg_stickers/releases/latest/download/amo-stickers.zip) — это
   всегда последняя версия.
2. Удалите всё содержимое папки расширения, саму папку оставьте. Распаковка поверх старых файлов оставила бы файлы,
   которых в новой версии уже нет.
3. Распакуйте новый архив в ту же папку.
4. На странице расширений (например, <CopyCode text="chrome://extensions" />) нажмите «Обновить» вверху страницы или значок «Перезагрузить» (круговая стрелка)
   на карточке amo stickers.
5. Перезагрузите вкладку amo.

![Страница расширений Chrome в режиме разработчика: кнопка «Обновить» вверху и значок «Перезагрузить» (круговая стрелка) на карточке amo stickers](img/update/extensions-reload.png)

::: warning Папка — та же
Новую версию распаковывайте в ту же папку, что и старую. Расширение из другой папки браузер считает новым
расширением, и ключи GIF и свой токен бота придётся вводить заново.
:::

Установленная версия видна на карточке amo stickers на странице расширений, последняя — на странице
[релизов](https://github.com/mcar2107/amo_msg_stickers/releases/latest).

## Userscript

Tampermonkey сам проверяет обновления скрипта и ставит новую версию. Проверить сразу можно из меню значка
Tampermonkey: «Утилиты» → «Проверить обновления скриптов». Новая версия заработает после перезагрузки вкладки amo.

![Меню значка Tampermonkey на странице amo: раскрыт раздел «Утилиты», пункт «Проверить обновления скриптов»](img/update/tampermonkey-check-updates.png)

В менеджерах без гарантий — Violentmonkey, Userscripts в Safari — автообновление не проверяется. Если новая версия
не пришла, поставьте её вручную по ссылке
[amo-stickers.user.js](https://github.com/mcar2107/amo_msg_stickers/releases/latest/download/amo-stickers.user.js).
