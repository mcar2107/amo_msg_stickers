# Ключи GIF

Поиск в режиме «GIF» работает через сервисы KLIPY и GIPHY. Общего ключа у amo stickers нет: каждый заводит свой
бесплатный ключ. Хватит одного, с двумя в режиме «GIF» будет больше источников, а у каждого — свой лимит запросов.

Ключи хранятся только в вашем браузере, и каждый уходит только в свой сервис: ключ KLIPY — в KLIPY, ключ GIPHY — в
GIPHY.

## KLIPY — рекомендуем

С KLIPY начните, если выбираете один сервис: выбор GIF и стикеров у него шире.

1. Откройте [Partner Panel KLIPY](https://partner.klipy.com/) и зарегистрируйтесь или войдите.
2. Перейдите на страницу ключей — [partner.klipy.com/api-keys](https://partner.klipy.com/api-keys). Нажмите
   «Add Platform» и укажите любое название, например `amo stickers`, затем у платформы нажмите «Create Key».
   Для amo stickers подходит тестовый ключ со статусом «Testing», который панель выдаёт сразу.
3. Нажмите «Show key» у ключа и скопируйте его.
4. В amo откройте панель amo stickers кнопкой стикеров в строке ввода, внизу панели нажмите «Настройки».
5. Вставьте ключ в поле «KLIPY API key». Ключ сохранится сам — как только вы перестанете печатать, уйдёте из поля
   или нажмёте Enter.

![Страница API Keys в Partner Panel KLIPY: платформа с приложением, скрытый ключ «Show key», статус «Testing» и кнопки «Add Platform» и «Create Key»](../img/setup/klipy-api-keys.png)

Когда вы уходите из поля или нажимаете Enter, amo stickers проверяет ключ запросом к сервису. Результат — под полем:

- «Проверяю ключ…» — проверка идёт;
- «Ключ работает» — всё готово;
- «KLIPY не принял ключ» — ключ скопирован не целиком или с лишними символами: скопируйте его заново и вставьте вместо
  старого;
- «Не удалось проверить ключ» — сервис не ответил: нет сети или ключ упёрся в [лимит запросов](#limits). Ключ
  сохранён, загляните в режим «GIF» позже.

Проверьте: в режиме «GIF» появился источник «KLIPY»: без запроса в ленте — тренды, с запросом — результаты
поиска.

![Режим «GIF» amo stickers: выбран источник «KLIPY», в ленте — результаты поиска по запросу «ганвест»](../img/setup/gif-mode-klipy.png)

## GIPHY

1. Откройте [панель разработчика GIPHY](https://developers.giphy.com/dashboard/) и зарегистрируйтесь или войдите.
2. Нажмите «Create an API Key», выберите тип «API», а не «SDK», и нажмите «Next Step».
3. Введите название и описание приложения — любые, например `amo stickers` и `Стикеры для amo`, — примите условия и
   создайте ключ.
4. Скопируйте ключ из списка приложений на панели.
5. В «Настройках» amo stickers вставьте ключ в поле «GIPHY API key». Он сохранится сам, а под полем появится результат
   проверки — как у ключа KLIPY, только с «GIPHY не принял ключ» при неверном ключе.

Проверьте: в режиме «GIF» появились источники «GIPHY» и «GIPHY стикеры». Оба работают на одном ключе GIPHY.

## Лимит запросов {#limits}

Бесплатные ключи — тестовые, и у них есть лимит запросов:

- **GIPHY** — 100 запросов в час;
- **KLIPY** — 100 запросов в час по данным KLIPY на момент написания; актуальная цифра — в Partner Panel.

Лимит у каждого ключа свой: ключ личный, и запросы других пользователей amo stickers его не тратят. Запрос тратят:

- **поиск** — каждый раз, когда вы перестали печатать в поле поиска;
- **подгрузка следующей страницы** — когда лента прокручена к концу, amo stickers загружает следующую порцию GIF;
- **тренды** — лента без запроса при открытии режима «GIF»;
- **проверка ключа** — один запрос, когда вы меняете ключ в «Настройках».

Источники «GIPHY» и «GIPHY стикеры» тратят один лимит — лимит ключа GIPHY.

**Если упёрлись в лимит**, поиск в этом источнике перестанет находить GIF, а в строке статуса появится ошибка.
Подождите: лимит — на час, и в течение часа поиск заработает снова. Или переключитесь на другой источник — если
ключа второго сервиса ещё нет, заведите его по шагам выше. Недавние GIF в ленте без запроса остаются под рукой.
