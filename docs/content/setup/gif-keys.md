# Ключи GIF

Поиск KLIPY работает сразу — на встроенном ключе amo stickers. Свои ключи необязательны:

- **ключ GIPHY** добавляет источники «GIPHY» и «GIPHY стикеры»;
- **свой ключ KLIPY** нужен, если встроенный недоступен — об этом скажет ошибка в режиме «GIF».

Ключи бесплатные, хранятся только в вашем браузере, и каждый уходит только в свой сервис.

## GIPHY

1. В [панели разработчика GIPHY](https://developers.giphy.com/dashboard/) нажмите «Create an API Key», тип — «API»,
   а не «SDK». Название и описание — любые.
2. Скопируйте ключ из списка приложений.
3. В amo stickers: «Настройки» → поле «GIPHY API key». Ключ сохраняется сам.

<img src="../img/setup/giphy-dashboard.png" alt="Окно «Create A New API Key» в панели разработчика GIPHY: выбран тип «API», кнопка «Next Step»" width="550">

Когда вы уходите из поля, ключ проверяется запросом к сервису, результат — под полем. «GIPHY не принял ключ» — ключ
скопирован не целиком. «Не удалось проверить ключ» — сервис не ответил; ключ сохранён.

Готово, если в режиме «GIF» рядом с «KLIPY» появились «GIPHY» и «GIPHY стикеры»:

![Режим «GIF» amo stickers: выбран источник «KLIPY», в ленте — результаты поиска по запросу «ганвест», под ней — подпись «Powered by KLIPY»](../img/setup/gif-mode-klipy.png)

## Свой ключ KLIPY {#own-klipy}

Нужен, только если в режиме «GIF» ошибка «Встроенный ключ KLIPY недоступен»: встроенный ключ общий на всех и может
упереться в лимит.

1. В [Partner Panel KLIPY](https://partner.klipy.com/api-keys) нажмите «Add Platform», название — любое, затем «Create
   Key». Подойдёт тестовый ключ со статусом «Testing».
2. «Show key» → скопируйте.
3. В amo stickers: «Настройки» → поле «Свой KLIPY API key».

![Страница API Keys в Partner Panel KLIPY: платформа с приложением, скрытый ключ «Show key», статус «Testing» и кнопки «Add Platform» и «Create Key»](../img/setup/klipy-api-keys.png)

## Лимит запросов {#limits}

У своих бесплатных ключей — 100 запросов в час (у KLIPY актуальная цифра — в Partner Panel), у каждого ключа свой.
Запрос тратят поиск, подгрузка следующей страницы ленты, тренды и проверка ключа; «GIPHY» и «GIPHY стикеры» делят один
лимит.

Упёрлись — подождите час или переключитесь на другой источник. Недавние GIF доступны и без запросов.
