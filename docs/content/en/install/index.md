# Installation

amo stickers works in the amo web app in a desktop browser. Choose your browser:

| Browser | How to install |
| --- | --- |
| [Google Chrome](./chromium) | extension or userscript |
| [Yandex Browser](./chromium) | extension or userscript |
| [Microsoft Edge](./chromium) | extension or userscript |
| [Opera](./chromium) | extension or userscript |
| [Brave, Vivaldi and other Chromium browsers](./chromium) | extension or userscript |
| [Firefox](./firefox) | userscript |
| [Safari](./safari) | userscript, no guarantees |

The **extension** is installed in the browser like any other add-on. The **userscript** is a script run by a script
manager such as Tampermonkey: handy if you already have one or can’t install the extension.

Install only one of them: the extension or the userscript, not both.
