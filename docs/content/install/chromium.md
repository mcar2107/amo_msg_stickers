# Chrome, Edge, Яндекс Браузер, Opera

Инструкция подходит и для других браузеров на Chromium — Brave, Vivaldi. Способов три, выберите один: расширение
из Chrome Web Store (рекомендуем), расширение из архива или userscript.

::::tabs
== Chrome Web Store
Рекомендуемый способ — расширение из Chrome Web Store: из магазина оно ставится в пару кликов и обновляется само.

1. Откройте страницу amo stickers в Chrome Web Store:
   [amo stickers](https://chromewebstore.google.com/detail/amo-stickers/abjnjphijggkkdbbmkldhibgepgdcgip).
2. Нажмите «Установить» и подтвердите установку.
3. Откройте или перезагрузите вкладку amo: в строке ввода рядом с кнопкой эмодзи появится кнопка стикеров.

В Edge на странице Chrome Web Store сначала нажмите «Разрешить расширения из других магазинов», в Opera — поставьте
расширение «Install Chrome Extensions»: без этого браузер не даст установить расширение из Chrome Web Store.

Если у вас уже стоит расширение из архива, удалите его перед установкой из магазина. Ключи GIF и свой токен бота,
если вы его задавали, придётся ввести заново, стикеры и паки останутся: они хранятся на сайте amo, а не в расширении.
== Архив
Архив — то же расширение, что в Chrome Web Store, только браузер ставит его из папки на компьютере.

::: warning Архив не обновляется сам
Новую версию нужно ставить вручную — как, написано ниже. Держите расширение в одной и той же папке: если распаковать
новую версию в другую папку, браузер сочтёт её новым расширением, и ключи GIF и свой токен бота, если вы его задавали,
придётся вводить заново.
:::

**Установка**

1. Скачайте архив последней версии:
   [amo-stickers.zip](https://github.com/mcar2107/amo_msg_stickers/releases/latest/download/amo-stickers.zip).
2. Заведите для расширения постоянную папку, например `Документы/amo-stickers`, и распакуйте архив в неё. В папке
   должен оказаться файл `manifest.json`. Не удаляйте и не переносите эту папку: браузер загружает расширение из неё.
3. Откройте страницу расширений — введите её адрес в адресной строке:

   | Браузер | Адрес |
   | --- | --- |
   | Chrome | <CopyCode text="chrome://extensions" /> |
   | Edge | <CopyCode text="edge://extensions" /> |
   | Яндекс Браузер | <CopyCode text="browser://extensions" /> |
   | Opera | <CopyCode text="opera://extensions" /> |
   | Brave | <CopyCode text="brave://extensions" /> |
   | Vivaldi | <CopyCode text="vivaldi://extensions" /> |

4. Включите переключатель «Режим разработчика». В Chrome, Яндекс Браузере и Opera он справа вверху страницы, в Edge —
   в панели слева.
5. Нажмите «Загрузить распакованное расширение» (в Edge кнопка может называться «Загрузить распакованное») и выберите
   папку из шага 2.
6. amo stickers появится в списке расширений. Откройте или перезагрузите вкладку amo: в строке ввода рядом с кнопкой
   эмодзи появится кнопка стикеров.

![Страница расширений Chrome: включён переключатель «Режим разработчика», под ним кнопка «Загрузить распакованное расширение»](../img/install/extensions-load-unpacked.png)

**Обновление**

1. Скачайте новый архив по той же ссылке:
   [amo-stickers.zip](https://github.com/mcar2107/amo_msg_stickers/releases/latest/download/amo-stickers.zip).
2. Удалите всё содержимое папки расширения, саму папку оставьте. Распаковка поверх старых файлов оставила бы файлы,
   которых в новой версии уже нет.
3. Распакуйте новый архив в ту же папку.
4. На странице расширений нажмите «Обновить» вверху страницы или значок «Перезагрузить» (круговая стрелка) на карточке amo stickers.
5. Перезагрузите вкладку amo.

Установленная версия видна на карточке amo stickers на странице расширений.
== Userscript
**Установите Tampermonkey.** Tampermonkey — менеджер скриптов, amo stickers проверяется в нём. Поставьте его с
[tampermonkey.net](https://www.tampermonkey.net/): сайт сам предложит магазин расширений вашего браузера. При установке
браузер предупредит, что расширению нужен доступ к данным на сайтах, — без него менеджер не запустит скрипт.

**Разрешите Tampermonkey запускать скрипты.** Браузеры на Chromium запускают пользовательские скрипты, только если
это разрешено отдельно:

1. Откройте страницу расширений (например, <CopyCode text="chrome://extensions" />) и у Tampermonkey нажмите «Сведения». Туда же ведёт
   пункт «Управление расширением» в меню значка Tampermonkey.
2. Включите переключатель «Разрешить пользовательские скрипты».
3. Если такого переключателя нет — так бывает в браузерах на старой версии Chromium, — включите «Режим разработчика»
   на странице расширений.

Без этого шага Tampermonkey установит скрипт, но не запустит его.

![Страница сведений Tampermonkey: включён переключатель «Разрешить пользовательские скрипты»](../img/install/allow-user-scripts.png)

::: info Violentmonkey — без гарантий
Скрипт может работать и в менеджере [Violentmonkey](https://violentmonkey.github.io/), но этот способ не проверяется.
Если в Violentmonkey что-то не работает, поставьте Tampermonkey по шагам выше или расширение из вкладки «Архив».
