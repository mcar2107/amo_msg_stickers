# Установка

amo stickers работает в веб-версии amo в браузере на компьютере. Выберите свой браузер:

| Браузер | Способы установки |
| --- | --- |
| [Google Chrome](./chromium) | расширение или userscript |
| [Яндекс Браузер](./chromium) | расширение или userscript |
| [Microsoft Edge](./chromium) | расширение или userscript |
| [Opera](./chromium) | расширение или userscript |
| [Brave, Vivaldi и другие на Chromium](./chromium) | расширение или userscript |
| [Firefox](./firefox) | userscript |
| [Safari](./safari) | userscript, без гарантий |

**Расширение** ставится в браузер как обычное дополнение. **Userscript** — скрипт, который запускает менеджер
скриптов, например Tampermonkey: удобно, если он у вас уже есть или расширение поставить нельзя.

Ставьте что-то одно: расширение или userscript, не оба сразу.
