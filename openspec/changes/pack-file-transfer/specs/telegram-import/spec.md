## MODIFIED Requirements

### Requirement: Форма импорта
У поля ссылки на сегменте «Telegram» SHALL быть видимая подпись «Ссылка на пак». Импорт MUST запускаться кнопкой
«Импорт» в футере экрана или Enter в поле; кнопка MUST быть недоступна, пока поле пустое, по ссылке нет пака (см.
«Карточка пака») или идёт импорт из файла (требование «Один импорт за раз» спеки `library-transfer`); во время импорта
на её месте MUST стоять «Отменить» (см. «Отмена импорта»). Ссылка, по которой нельзя определить имя пака, MUST
показываться ошибкой у поля без запроса к Telegram. Ошибка импорта, который завершился, пока открыт сегмент
«Telegram», MUST показываться у поля ссылки, а не в строке статуса; ошибка импорта, завершившегося на другом экране
или режиме, MUST показываться в строке статуса. Введённая ссылка MUST сохраняться при уходе с экрана и смене сегмента
до успешного импорта; после успешного импорта поле MUST быть пустым.

#### Scenario: Неверная ссылка
- **WHEN** пользователь вводит `hello world` и нажимает Enter
- **THEN** у поля ошибка о неверной ссылке, поле отмечено недействительным, запросов к Telegram нет

#### Scenario: Пак не найден
- **WHEN** на открытом сегменте «Telegram» импорт завершается ошибкой «пак не найден»
- **THEN** ошибка показана у поля ссылки, строка статуса её не дублирует

#### Scenario: Уход во время импорта
- **WHEN** пользователь запустил импорт, нажал «Назад» и снова открыл сегмент «Telegram»
- **THEN** в поле та же ссылка, в футере «Отменить», в карточке пака виден прогресс

#### Scenario: Импорт из файла идёт
- **WHEN** идёт импорт из файла, а в поле ссылки — ссылка на существующий пак, и пользователь нажимает Enter
- **THEN** импорт из Telegram не начинается, «Импорт» недоступна до конца импорта из файла
