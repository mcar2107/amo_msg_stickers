## MODIFIED Requirements

### Requirement: Форма импорта
У поля ссылки на сегменте «Telegram» SHALL быть видимая подпись «Ссылка на пак». Импорт MUST запускаться кнопкой
«Импорт» в футере экрана или Enter в поле; кнопка MUST быть недоступна, пока поле пустое, по ссылке нет пака (см.
«Карточка пака») или идёт импорт из файла (требование «Один импорт за раз» спеки `library-transfer`); во время импорта
на её месте MUST стоять «Отменить» (см. «Отмена импорта»). Ссылка, по которой нельзя определить имя пака, MUST
показываться ошибкой у поля без запроса к Telegram. Ошибка импорта, который завершился, пока открыт сегмент
«Telegram», MUST показываться у поля ссылки, а не в строке статуса; ошибка импорта, завершившегося на другом экране
или режиме, MUST показываться в строке статуса. Введённая ссылка MUST сохраняться при уходе с экрана и смене сегмента
до успешного импорта; после успешного импорта поле MUST быть пустым.

#### Scenario: Неверная ссылка
- **WHEN** пользователь вводит `hello world` и нажимает Enter
- **THEN** у поля ошибка о неверной ссылке, поле отмечено недействительным, запросов к Telegram нет

#### Scenario: Пак не найден
- **WHEN** на открытом сегменте «Telegram» импорт завершается ошибкой «пак не найден»
- **THEN** ошибка показана у поля ссылки, строка статуса её не дублирует

#### Scenario: Уход во время импорта
- **WHEN** пользователь запустил импорт, нажал «Назад» и снова открыл сегмент «Telegram»
- **THEN** в поле та же ссылка, в футере «Отменить», в карточке пака виден прогресс

#### Scenario: Импорт из файла идёт
- **WHEN** идёт импорт из файла, а в поле ссылки — ссылка на существующий пак, и пользователь нажимает Enter
- **THEN** импорт из Telegram не начинается, «Импорт» недоступна до конца импорта из файла

### Requirement: Прогресс и частичные сбои
Во время импорта система SHALL показывать в карточке пака под полем ссылки (см. «Карточка пака») полосу прогресса
и счётчик «N/M» (обработано из всего) на месте числа стикеров. Пока открыт сегмент «Telegram», строка статуса ход импорта MUST NOT дублировать; ушедший с
экрана или на другой сегмент MUST видеть ход в строке статуса — ««<название>»: N/M» на языке интерфейса (см.
`localization`). Раздел пака и его вкладка MUST появляться в ленте режима «Стикеры» после первого сконвертированного
стикера. Ошибка одного стикера MUST NOT прерывать импорт остальных, кроме отказа встроенного бота (см. «Отказ
встроенного бота»). Если не удалось импортировать ни одного стикера пака, строка статуса MUST показывать причину первого
отказа (после отказа встроенного бота — его ошибку), а не общую ошибку пака; общая ошибка «в паке нет пригодных
стикеров» остаётся для пака, в котором не было ни одного стикера. После завершения, если пользователь всё ещё на экране
«Добавить стикеры», система MUST вернуться в режим «Стикеры» и прокрутить ленту к разделу импортированного пака.
Фокус после такого перехода MUST NOT падать в `body`: он MUST встать на вкладку раздела импортированного пака. Фокус,
который пользователь за время импорта увёл из попапа, например в поле ввода amo, MUST NOT забираться.

#### Scenario: Счётчик в карточке
- **WHEN** на сегменте «Telegram» идёт импорт пака из 34 стикеров, и обработано 12
- **THEN** в карточке пака — его название, «12/34» и полоса прогресса, строка статуса пуста

#### Scenario: Ход импорта вне экрана
- **WHEN** во время импорта пользователь нажимает «Назад»
- **THEN** ход импорта ««<название>»: N/M» виден в строке статуса режима

#### Scenario: Один стикер не сконвертировался
- **WHEN** один из 30 стикеров не удалось скачать или сконвертировать
- **THEN** импорт доходит до 30/30, в паке 29 стикеров

#### Scenario: Ни один стикер не импортирован
- **WHEN** ни один стикер пака не удалось скачать или сконвертировать, и первый отказ — файл больше 5 МБ
- **THEN** раздел пака не появился (прежний импорт того же пака остаётся как был), в строке статуса ошибка лимита
  «5 МБ» на языке интерфейса

#### Scenario: Пустой пак
- **WHEN** Bot API вернул пак без стикеров
- **THEN** раздел пака не появился, в строке статуса «в паке нет пригодных стикеров» на языке интерфейса

#### Scenario: Завершение импорта
- **WHEN** импорт пака завершился, пока открыт экран «Добавить стикеры»
- **THEN** открыт режим «Стикеры», вверху ленты — заголовок импортированного пака, его вкладка подсвечена

#### Scenario: Фокус после импорта с клавиатуры
- **WHEN** пользователь нажал Enter в поле ссылки, и импорт пака «Утята» завершился, пока открыт экран «Добавить стикеры»
- **THEN** лента стоит у раздела «Утята», фокус на его вкладке

#### Scenario: Фокус увели из попапа во время импорта
- **WHEN** во время импорта пользователь перевёл фокус в поле ввода amo, а импорт завершился, пока открыт экран
  «Добавить стикеры»
- **THEN** фокус остаётся в поле ввода amo
