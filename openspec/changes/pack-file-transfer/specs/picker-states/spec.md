## MODIFIED Requirements

### Requirement: Каркас экрана
Экран «Добавить стикеры» и «Настройки» SHALL быть областью с именем из своего заголовка: сверху — кнопка «Назад» и заголовок, ниже — прокручиваемое содержимое. У экрана «Добавить стикеры» внизу — футер вне прокрутки с главной кнопкой экрана; у «Настроек» футера нет: главного действия у них нет, значения сохраняются сами. Главная кнопка MUST быть видна без прокрутки на панели 350×400 px при любой длине содержимого, в том числе после выбора файла с превью, при раскрытой инструкции импорта и при карточке файла с несколькими паками. При открытии экрана кликом или с клавиатуры фокус MUST переходить в первое текстовое поле формы экрана: в «Настройках» — ключ KLIPY, в «Добавить стикеры» — первое текстовое поле открытого сегмента («Ссылка на пак» у «Telegram», «Подпись» у «Свой стикер»). У сегмента «Файл» текстового поля нет, и фокус MUST вставать на его вкладку сегмента, а не на кнопку выбора файла: Enter по привычке не открывает диалог файла. Смена сегмента фокус с вкладки сегмента MUST NOT уводить. При повторном открытии попапа на уже открытом экране фокус MUST NOT переноситься принудительно.

#### Scenario: Кнопка без прокрутки
- **WHEN** на сегменте «Свой стикер» выбран файл и показано превью
- **THEN** кнопка «Сохранить в «Мои стикеры»» видна в футере экрана без прокрутки

#### Scenario: Фокус при открытии экрана
- **WHEN** фокус на кнопке «Настройки» футера и пользователь нажимает Enter
- **THEN** открывается экран, фокус в поле ключа KLIPY, скринридер читает его подпись

#### Scenario: Фокус при открытии «Добавить стикеры»
- **WHEN** пользователь нажимает «+» справа от полосы вкладок, а последним выбран сегмент «Telegram»
- **THEN** экран открыт на сегменте «Telegram», фокус в поле «Ссылка на пак»

#### Scenario: Фокус на сегменте «Файл»
- **WHEN** пользователь нажимает «+», а последним выбран сегмент «Файл»
- **THEN** экран открыт на сегменте «Файл», фокус на его вкладке

#### Scenario: Карточка файла с пятью паками
- **WHEN** на сегменте «Файл» выбран файл библиотеки из пяти паков
- **THEN** «Импорт» видна в футере без прокрутки, список паков прокручивается в теле экрана
