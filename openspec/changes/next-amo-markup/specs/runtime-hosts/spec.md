## MODIFIED Requirements

### Requirement: Агент в мире страницы
Внутренний путь отправки amo доступен только скриптам страницы, поэтому в мире страницы SHALL выполняться агент, который
умеет две вещи: отправить переданный ему файл отдельным сообщением в открытый чат amo — ответом на сообщение, если в
поле ввода этого чата активен ответ, — и после отправки снять этот ответ; и в Worker-версии amo web пометить строки ленты
с картинкой amo stickers атрибутом её вида, а их коробки медиа — сторонами картинки (требование «Распознавание своего
сообщения»). Агент MUST NOT
отдавать странице и вызывающей стороне ничего, кроме статуса команды и причины отказа, а в ленте — ничего, кроме вида и
сторон картинки сообщений amo stickers: ни код ядра, ни API менеджера, ни настройки, ни содержимое поля ввода,
ни сообщение, на которое отвечают. Команды агенту видны скриптам страницы; через агента страница MUST NOT получать
возможностей сверх тех, что у неё уже есть, — отправить файл в открытый чат ответом и снять ответ она может и сама.

Агент SHALL запускаться до скриптов страницы: в Worker-версии amo web ядро страницы доступно только тому, кто начал
работу раньше неё. Агент MUST NOT менять поведение страницы: создание Worker-ов страницей, их сообщения, ошибки и
остановка MUST проходить как без агента, а без команды агент только помечает строки ленты. Ядро amo stickers SHALL стартовать после загрузки DOM, как
раньше.

#### Scenario: Посторонняя команда
- **WHEN** скрипт страницы шлёт агенту команду в неверном формате
- **THEN** агент ничего не отправляет и не отвечает

#### Scenario: Ответ не раскрывает черновик
- **WHEN** агент отправил стикер при тексте в поле ввода и активном ответе на сообщение
- **THEN** в его ответах нет текста поля, вложений, настроек и сообщения, на которое отвечают, — только статус

#### Scenario: Запуск до страницы
- **WHEN** пользователь открывает Worker-версию amo web с установленным расширением или userscript в Tampermonkey
- **THEN** агент запущен до скриптов страницы, и стикер уходит прямой отправкой, без вставки в поле

#### Scenario: Страница без amo stickers не отличается
- **WHEN** агент запущен, а пользователь стикеры не отправляет
- **THEN** страница amo работает как без него: чаты открываются, сообщения отправляются, перезапуск ядра страницы после
  его сбоя проходит

#### Scenario: Пометка ленты не выдаёт чужое
- **WHEN** в ленте Worker-версии сообщения с картинками `photo.jpg` и `😀.amostk.k-sticker.gif`
- **THEN** атрибут вида агента — только у строки со стикером, переменные сторон — только у её коробки медиа; в них
  только вид и стороны картинки
