## Context

Кнопка стикеров копирует классы иконки эмодзи своей разметки (`ButtonMarkup`), а цвет закрытого и открытого состояния
переключает `app.ts` заменой `idleClasses` / `openClasses`. В стабильной и прежней разметке иконка эмодзи в режиме
редактирования получает `dark:fill-gray-40` вместо `dark:fill-gray-70`; светлый `fill-cadetGray-30` не меняется, а
открытый эмодзи (`fill-blue-50 dark:fill-beige-70`) перекрывает цвет редактирования. Иконка эмодзи Worker-версии —
`text-fg-muted` при любом черновике. Признак редактирования разметки уже есть — `AmoMarkup.isEditing(composer)`.

## Goals / Non-Goals

**Goals:**
- Три состояния цвета иконки: покой, покой в редактировании, открыт — классы каждого заменяют классы остальных.
- Цвет следует за входом в редактирование и выходом из него без перезагрузки и без своих наблюдателей.

**Non-Goals:**
- Переход цвета при входе в редактирование и наведение — не меняются.
- Worker-версия: у её кнопки эмодзи состояния редактирования нет.

## Decisions

- **`editClasses` в `ButtonMarkup`, необязательное.** Классы цвета покоя на время редактирования, заменяют
  `idleClasses`. Разметка без них (Worker-версия) редактирование цветом не отмечает. Альтернатива — правило CSS в листе
  стиля ленты с `:has()` по признаку правки — отвергнута: лист только для ленты, а `:has()` на поле дорог («Стиль»).
- **Выбор классов — чистая функция** от `isOpen` и `isEditing`: какие классы снять и какие поставить. Тестируется без DOM.
- **Пересчёт — в `scan()`.** Вход в редактирование и выход из него в стабильной и прежней разметке монтирует и снимает
  узлы строки поля (кнопка вложений есть только вне редактирования), и наблюдатель `body` ставит поиск полей на кадр. В
  нём для уже вставленных кнопок цвет пересчитывается по текущему признаку редактирования поля. Свой наблюдатель
  атрибутов `data-visible` / `class` кнопки отмены правки не нужен.

## Risks / Trade-offs

- [amo перестанет менять узлы строки при входе в правку] → цвет обновится на следующей мутации `body` или открытии
  попапа; проверяется на стенде и в живом amo.
- [Пересчёт на каждом кадре поиска] → проверка признака — один `querySelector` на поле, классы пишутся только при смене.
