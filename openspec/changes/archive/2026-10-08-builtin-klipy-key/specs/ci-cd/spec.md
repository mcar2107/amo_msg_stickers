## ADDED Requirements

### Requirement: Встроенный ключ KLIPY в сборке
Сборка SHALL встраивать ключ KLIPY из переменной окружения `KLIPY_API_KEY` в расширение и userscript. Сборка в CI SHALL
получать его из секрета репозитория `KLIPY_API_KEY`, а релиз MUST выкладывать сборку с ним. Без переменной сборка MUST
проходить и MUST NOT содержать ключа. Значение, в котором после снятия пробелов по краям есть символы вне
`[A-Za-z0-9_-]`, MUST ронять сборку с ошибкой, в которой нет самого значения. Ключ MUST NOT лежать в git и MUST NOT
печататься в логах сборки.

#### Scenario: Релиз
- **WHEN** в `master` мержится PR с новой версией, секрет `KLIPY_API_KEY` задан
- **THEN** в `amo-stickers.zip` и `amo-stickers.user.js` релиза поиск KLIPY работает без своего ключа

#### Scenario: Сборка без секрета
- **WHEN** сборка идёт без переменной `KLIPY_API_KEY` — локально, в `pnpm watch` или в PR из форка
- **THEN** сборка проходит, а режим «GIF» без своих ключей показывает подсказку про API-ключ

#### Scenario: Битое значение
- **WHEN** переменная `KLIPY_API_KEY` задана строкой с пробелом внутри или кавычкой
- **THEN** сборка падает с ошибкой о формате ключа, значение переменной в выводе не появляется
