## MODIFIED Requirements

### Requirement: Браузерное расширение
Система SHALL поставляться как Chrome MV3-расширение, которое в боевой сборке запускается только на страницах `https://*.amo.tm/*`. Сборка для разработки (`pnpm watch`) MUST дополнительно запускаться на `http://localhost:3000/*` и `http://127.0.0.1:3000/*`. Расширение MUST запрашивать только разрешение `storage` и доступ к хостам GIPHY, KLIPY и Telegram API.

#### Scenario: Установка распакованного расширения
- **WHEN** пользователь загружает `dist/extension` как распакованное расширение и открывает web.amo.tm
- **THEN** в поле ввода появляется кнопка стикеров, в консоли страницы строка `[amo-stickers] started (extension)`

#### Scenario: Боевая сборка без локальных адресов
- **WHEN** выполняется `pnpm build`
- **THEN** ни `dist/extension/manifest.json`, ни заголовок `dist/amo-stickers.user.js` не содержат `localhost` и `127.0.0.1`

#### Scenario: Сборка для разработки
- **WHEN** выполняется `pnpm watch`
- **THEN** `dist/extension/manifest.json` содержит `http://localhost:3000/*` и `http://127.0.0.1:3000/*` в `content_scripts`

## ADDED Requirements

### Requirement: Сетевая политика
Оба окружения MUST выполнять сетевые запросы только по `https` к хосту `api.telegram.org` (без поддоменов) и к `giphy.com` и `klipy.com`, включая их поддомены. Хост MUST определяться разбором URL, а не сравнением строки. Запрос к другому адресу MUST завершаться ошибкой без обращения к сети. Если ответ пришёл после редиректа на адрес вне политики, запрос MUST завершаться ошибкой. В расширении service worker MUST отвечать только на сообщения от content script этого же расширения.

#### Scenario: Чужой хост
- **WHEN** ядро запрашивает `https://evil.example/x.gif`
- **THEN** запрос не выполняется, возвращается ошибка «Адрес вне списка разрешённых»

#### Scenario: Похожий домен
- **WHEN** ядро запрашивает `https://giphy.com.evil.example/x.gif` или `https://api.telegram.org@evil.example/`
- **THEN** запрос не выполняется

#### Scenario: Не https
- **WHEN** ядро запрашивает `http://media.giphy.com/x.gif`
- **THEN** запрос не выполняется

#### Scenario: Сообщение от чужого отправителя
- **WHEN** service worker получает `amo-stickers:fetch` не от вкладки этого расширения
- **THEN** он не выполняет запрос и не отвечает

### Requirement: Лимит размера загрузки
Загрузка бинарного файла SHALL принимать максимальный размер. Тело ответа MUST читаться потоком, и при превышении лимита чтение MUST прерываться с ошибкой «Файл больше N МБ», не дочитывая остаток. В расширении лимит MUST применяться в service worker до передачи данных в content script.

#### Scenario: Сервер не сообщил размер
- **WHEN** ответ без `Content-Length` оказывается больше лимита
- **THEN** чтение прерывается на превышении, возвращается ошибка «Файл больше N МБ»

#### Scenario: Сервер сообщил размер больше лимита
- **WHEN** `Content-Length` ответа больше лимита
- **THEN** тело не читается, возвращается та же ошибка
