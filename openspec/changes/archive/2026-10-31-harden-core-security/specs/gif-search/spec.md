## ADDED Requirements

### Requirement: Проверка ответа источника
Система MUST проверять форму ответа GIPHY и KLIPY перед использованием. Ответ, в котором нет списка выдачи или данных пагинации нужного типа, MUST приводить к ошибке источника (по правилам «Ошибки источника»). Элемент выдачи без пригодного варианта для превью или отправки либо со ссылкой вне сетевой политики (`runtime-hosts`) MUST отбрасываться, остальные элементы страницы MUST показываться.

#### Scenario: Битый ответ
- **WHEN** GIPHY возвращает JSON без поля `data`
- **THEN** в статусе попапа показано «GIF: GIPHY: неожиданный ответ», уже загруженная выдача сохраняется

#### Scenario: Элемент без рендишна
- **WHEN** в выдаче GIPHY у одного элемента нет ни `downsized`, ни `original`
- **THEN** этот элемент не показывается, остальные показаны

#### Scenario: Ссылка на чужой хост
- **WHEN** у элемента выдачи KLIPY ссылка на GIF ведёт вне `klipy.com`
- **THEN** элемент не показывается
