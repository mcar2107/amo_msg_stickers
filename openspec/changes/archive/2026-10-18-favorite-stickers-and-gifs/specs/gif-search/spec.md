## MODIFIED Requirements

### Requirement: Тренды и поиск
При пустом запросе система SHALL показывать раздел избранных GIF (если они есть, спека `favorites`), под ним — раздел недавних GIF (если есть недавние GIF не из избранного), а под ними — трендовую выдачу выбранного источника. Избранные и недавние GIF MUST показываться при любом выбранном источнике. При вводе запроса поиск MUST выполняться через 350 мс после последнего нажатия клавиши; при непустом запросе избранные и недавние GIF не показываются. Выдача показывается в две колонки с сохранением пропорций превью, в порядке выдачи: каждый следующий элемент встаёт в более короткую колонку, при равенстве — в левую. Подгрузка следующей страницы MUST NOT сдвигать уже показанные элементы. В документе присутствуют только элементы видимой области и небольшой запас вокруг неё; GIF вне экрана MUST NOT проигрываться.

#### Scenario: Ввод запроса
- **WHEN** пользователь вводит «кот» и перестаёт печатать
- **THEN** через 350 мс выдача заменяется результатами по запросу «кот», разделов избранного и недавних нет

#### Scenario: Пустой результат
- **WHEN** по запросу ничего не найдено
- **THEN** показан текст «Ничего не нашлось»

#### Scenario: Недавние перед трендами
- **WHEN** пользователь отправлял GIF, избранных GIF нет, и он открывает режим «GIF» с пустым запросом
- **THEN** сверху раздел недавних GIF, под ним тренды выбранного источника

#### Scenario: Избранное перед недавними
- **WHEN** у пользователя есть избранные и недавние GIF, и он открывает режим «GIF» с пустым запросом
- **THEN** сверху раздел избранных GIF, под ним недавние, под ними тренды выбранного источника

#### Scenario: Порядок выдачи
- **WHEN** показана выдача из GIF одинаковой формы
- **THEN** первый GIF слева вверху, второй справа вверху, третий слева под первым

#### Scenario: Длинная выдача
- **WHEN** пользователь подгрузил 10 страниц выдачи и прокручивает её
- **THEN** в документе отрисованы только GIF видимой области и запаса, прокрутка идёт без подвисаний

### Requirement: Доступные источники
Система SHALL показывать источники по ключам: при своём ключе GIPHY — «GIPHY» (гифки) и «GIPHY стикеры», при своём ключе KLIPY или встроенном ключе KLIPY сборки — «KLIPY». Запросы к KLIPY MUST идти по своему ключу, если он задан, иначе — по встроенному. GIPHY MUST работать только по своему ключу. Если нет ни своих ключей, ни встроенного ключа KLIPY, режим «GIF» MUST показывать подсказку, кнопку, открывающую настройки, и ссылку на страницу доки о получении ключей (в новой вкладке, на языке интерфейса: из английского — английская страница, из русского — русская) вместо поиска и трендов; избранные и недавние GIF при этом остаются. Если источников больше одного, система MUST показывать переключатель между ними.

#### Scenario: Чистая установка со встроенным ключом
- **WHEN** в сборке есть встроенный ключ KLIPY, и пользователь без сохранённых ключей открывает режим «GIF»
- **THEN** показаны тренды KLIPY, поиск отдаёт выдачу KLIPY, переключателя источников нет

#### Scenario: Свой ключ KLIPY важнее встроенного
- **WHEN** в сборке есть встроенный ключ KLIPY, а в «Настройках» сохранён свой
- **THEN** запросы к KLIPY идут со своим ключом

#### Scenario: Ключ GIPHY при встроенном ключе
- **WHEN** в сборке есть встроенный ключ KLIPY, а в «Настройках» сохранён только ключ GIPHY
- **THEN** над выдачей есть переключатель «GIPHY», «GIPHY стикеры», «KLIPY»

#### Scenario: Нет ключей
- **WHEN** в сборке нет встроенного ключа KLIPY, и пользователь открывает режим «GIF» без сохранённых ключей
- **THEN** показан текст «Для поиска GIF нужен API-ключ GIPHY или KLIPY», кнопка «Открыть настройки» и ссылка на инструкцию; по нажатию кнопки открывается экран «Настройки»

#### Scenario: Инструкция по ключам
- **WHEN** пользователь без ключей нажимает ссылку на инструкцию в режиме «GIF»
- **THEN** в новой вкладке открывается страница доки о ключах GIF

#### Scenario: Инструкция по ключам на английском
- **WHEN** интерфейс на английском и пользователь без ключей нажимает ссылку на инструкцию в режиме «GIF»
- **THEN** в новой вкладке открывается английская страница доки о ключах GIF

#### Scenario: Оба ключа
- **WHEN** сохранены ключи GIPHY и KLIPY
- **THEN** над выдачей есть переключатель «GIPHY», «GIPHY стикеры», «KLIPY»

#### Scenario: Избранное без ключей
- **WHEN** у пользователя есть избранные GIF, ни своих ключей, ни встроенного ключа KLIPY нет, и он открывает режим «GIF»
- **THEN** показаны подсказка с кнопкой настроек и раздел избранных GIF, GIF из него отправляется
