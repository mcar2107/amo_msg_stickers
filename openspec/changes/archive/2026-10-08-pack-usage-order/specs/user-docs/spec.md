## ADDED Requirements

### Requirement: Порядок паков в доке
Частые вопросы доки SHALL объяснять, в каком порядке стоят паки в режиме «Стикеры»: «Недавние» и «Мои стикеры»
первыми, затем паки Telegram по последней отправке из раздела пака; новый пак — первым; отправка из «Недавних»
порядок не меняет; порядок обновляется при следующем открытии панели. Раздел MUST быть на русском и английском, а
ручной перестановки паков он MUST NOT обещать.

#### Scenario: Пак переехал
- **WHEN** пользователь видит, что пак в ленте сменил место, и ищет причину в доке
- **THEN** он находит в частых вопросах объяснение порядка по последней отправке

#### Scenario: Английская дока
- **WHEN** пользователь открывает частые вопросы на английском
- **THEN** там тот же вопрос о порядке паков с названиями экранов английского интерфейса
