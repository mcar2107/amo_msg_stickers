### G5 · Импорт из Telegram

Решения: ход импорта вынесен в чистый runPackImport (PickerProvider/runPackImport/, новый модуль вне списка файлов G5) с тестами; importPack() без аргумента, ссылка в провайдере; ошибка у поля снимает статус (clearStatus); ссылка без имени пака — всегда ошибка у поля; «?» — HintToggle absolute над строкой подписи (не в <label>); инструкция — свой <p id hidden> для aria-controls; useImportHint повторяет обёртку PAGE_STORAGE (та не экспортирована).
Решения координатора: G5 правит AddView.tsx (провод fieldError) — волна последовательная; удаление неиспользуемого add.telegram.hint из словарей поручено G5 координатором — аудитор поднял его critical по K5, снято решением (ключ нигде не используется, дерево общее), круга нет.
