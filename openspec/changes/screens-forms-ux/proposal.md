## Why

Экраны «Настройки» и «Добавить стикеры» в панели пикера (около 350×400 px) неудобны (issue #91): главное действие
лежит ниже сгиба и закрывается строкой статуса, Enter не отправляет форму, поля без видимых подписей, заголовок экрана
не заголовок, несохранённые ключи теряются молча, а длинная инструкция импорта стоит над полем ссылки при каждом
открытии (issue #89, входит в это изменение).

## What Changes

- **Каркас экрана.** У экрана — настоящий заголовок `h2`, при открытии фокус переходит на него; снизу — футер экрана
  вне прокрутки с главной кнопкой. Строка статуса на экране встаёт над футером экрана, а не поверх него.
- **Формы.** Поля лежат в `<form>`: Enter в любом поле выполняет главное действие (с той же недоступностью, что у
  кнопки). У каждого поля — постоянная видимая подпись, подсказки и ошибки привязаны к полю `aria-describedby`.
  Ошибка, относящаяся к полю, показывается у поля.
- **«Добавить стикеры» — два сегмента** «Telegram» и «Свой стикер» (ARIA tabs), у каждого одна форма и своя кнопка в
  футере («Импорт» / «Сохранить в «Мои стикеры»»). «+» открывает последний выбранный сегмент (по умолчанию
  «Telegram»), плитка «Создать стикер» — «Свой стикер».
- **Импорт из Telegram.** Подпись поля «Ссылка на пак»; введённая ссылка переживает уход с экрана, пока импорт не
  закончился успехом; неверная ссылка и ошибка импорта, завершившегося на открытом сегменте, — у поля.
- **Инструкция импорта (#89).** Полная инструкция показывается при первом показе сегмента «Telegram», затем скрыта;
  кнопка «?» у поля раскрывает её снова. Признак «показано» — в `localStorage` страницы, сбой хранилища — инструкция
  показывается.
- **Свой стикер.** Зона загрузки с иконкой и кнопкой «Выбрать файл» (имя доступности — из словаря, без строки
  браузера «Файл не выбран»), видимый фокус, после выбора — имя файла и «Заменить». Пока стикер собирается — индикатор
  на превью и причина недоступности кнопки сохранения. Видимая подпись поля «Подпись».
- **Настройки — автосохранение.** **BREAKING (поведение):** кнопки «Сохранить» нет. Значение сохраняется при уходе
  из поля, по Enter, при «Назад», переключении режима и закрытии попапа — правки не теряются. В футере — «Готово»,
  которая возвращает в режим. Поля сгруппированы: «GIF» (KLIPY, GIPHY — «достаточно одного ключа») и «Telegram»
  (токен); ссылка на доку — одна на группу; «хранится только в этом браузере» — одна строка на экран.
- **Проверка введённого.** Изменённый ключ GIF после сохранения проверяется запросом к API источника, токен
  Telegram — по формату. Результат — у поля: «ключ работает», «ключ не принят», «не удалось проверить». Проверка
  MUST NOT блокировать сохранение ни при каком исходе — только предупреждение.
- **«Показать».** Ключи и токен скрыты как пароль, у каждого поля — кнопка «Показать» / «Скрыть».
- **Иерархия.** Заголовок экрана заметно крупнее заголовков групп и подписей; отступ между группами больше отступа
  внутри группы; шрифт полей один на оба экрана.
- Строки — через словарь `ru` / `en`; дока (оба языка) описывает автосохранение и новые экраны.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `picker-states`: заголовок экрана, футер экрана с главной кнопкой, строка статуса над ним, фокус при открытии
  экрана, формы с отправкой Enter и подписями полей.
- `composer-integration`: навигация попапа — сегменты «Добавить стикеры» и какой сегмент открывают «+» и плитка.
- `custom-stickers`: зона загрузки, состояние сборки, сохранение кнопкой футера и Enter, плитка открывает сегмент
  «Свой стикер».
- `telegram-import`: форма импорта (подпись, Enter, ошибка у поля, ссылка переживает уход), подсказка импорта
  показывается при первом показе и раскрывается «?».
- `runtime-hosts`: настройки — автосохранение, группы, «Показать», проверка ключей и токена; подсказки настроек — одна
  ссылка на доку на группу.
- `user-docs`: шаги настройки ключей и токена без кнопки «Сохранить».

## Impact

- UI: `src/core/ui/Picker/Screen/`, `AddView/` (сегменты, `TelegramImport/`, `CreateSticker/`, `DropZone/`),
  `SettingsView/` (`SecretField/`, `useSettingsDraft/`), `StatusBar/`, `TextInput/`, `ViewHeader/`, `ViewBody/`,
  `usePickerView/` (сегмент экрана «Добавить»), `PickerProvider/usePackImport.ts` (ссылка и ошибка поля),
  `StickersMode/` (`AddButton/`, `StickerFeed/CreateTile/`).
- Ядро: проверка ключей GIF (`sources/gifs.ts`), формат токена (`sources/telegram.ts`), признак показа инструкции в
  `localStorage` (рядом с `pickerMode.ts`).
- Словари `messages.ru.ts` / `messages.en.ts`: новые ключи, удаление `settings.save`.
- Дока: `docs/content/setup/gif-keys.md`, `setup/telegram.md` и их английские пары; скрин `img/setup/telegram-import.png`.
- Зависимостей не добавляет. Схема хранения не меняется.
