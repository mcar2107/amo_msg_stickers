## MODIFIED Requirements

### Requirement: Запись в недавние
После успешной отправки система SHALL добавить элемент в начало недавних его вида: стикер — в недавние стикеры, GIF из
каталогов — в недавние GIF, в том числе отправленный из избранного. Отправка считается успешной, когда amo принял сообщение: через очередь — принял его в
очередь, на запасном пути — нажата «Отправить»; исход загрузки и доставки на это не влияет. Если стикер не отправлен,
недавние MUST NOT меняться. Элемент из избранного записывается в недавние, но в них не показывается (требование
«Недавние» спеки `sticker-library`).

#### Scenario: Недавние после отправки
- **WHEN** стикер успешно отправлен
- **THEN** он первый в разделе «Недавние» режима «Стикеры», если его нет в избранном

#### Scenario: Отправка из избранного
- **WHEN** пользователь отправляет стикер из раздела «Избранное»
- **THEN** стикер остаётся в «Избранном» на своём месте и не появляется в «Недавних»

#### Scenario: Недавние после отправки GIF
- **WHEN** GIF из поиска успешно отправлен
- **THEN** он первый в разделе недавних режима «GIF»

### Requirement: Метка в имени файла
Имя отправляемого файла SHALL иметь формат `[<метка>.]amostk.k-<вид>[.<ключ>-<значение>]*.<расширение>`:

- `amostk` — маркер «отправлено amo stickers»;
- вид — `sticker` для стикера из пака (своего или импортированного из Telegram), `gif` для GIF из поиска GIPHY или
  KLIPY; при отправке из «Недавних» и «Избранного» вид MUST совпадать с видом исходного элемента;
- параметры `<ключ>-<значение>` необязательны; при разборе имени их порядок MUST NOT иметь значения, а незнакомый
  ключ, сегмент не в форме `<ключ>-<значение>` и незнакомый вид MUST NOT делать имя чужим — имя с маркером остаётся
  именем amo stickers;
- расширение MUST присутствовать и соответствовать содержимому — `gif`;
- метка для людей — эмодзи Telegram-стикера, подпись своего стикера или название GIF. Из метки MUST вычищаться
  символы `.` и `/`, управляющие символы и символы управления направлением текста; пробелы по краям MUST
  обрезаться. Длина метки MUST быть не больше 32 символов, где символ — графема: составной эмодзи или буква с
  диакритикой — один символ, и не больше 128 байт в UTF-8; символ MUST NOT разрезаться. Пустая метка MUST NOT
  писаться, и имя начинается с `amostk.`.

#### Scenario: Стикер из Telegram с эмодзи
- **WHEN** пользователь отправляет стикер из импортированного пака с эмодзи 😀
- **THEN** файл называется `😀.amostk.k-sticker.gif`

#### Scenario: Свой стикер с подписью
- **WHEN** пользователь отправляет свой стикер с подписью «Привет»
- **THEN** файл называется `Привет.amostk.k-sticker.gif`

#### Scenario: GIF из поиска
- **WHEN** пользователь отправляет GIF из поиска с названием `cat`
- **THEN** файл называется `cat.amostk.k-gif.gif`

#### Scenario: Отправка из «Недавних»
- **WHEN** пользователь повторно отправляет из «Недавних» GIF, найденную поиском
- **THEN** имя файла содержит `.k-gif.`, а не `.k-sticker.`

#### Scenario: Без метки
- **WHEN** у стикера нет ни эмодзи, ни подписи
- **THEN** файл называется `amostk.k-sticker.gif`

#### Scenario: Метка с точками, слешами и длинная
- **WHEN** название GIF — `a.b/c` или строка длиннее 32 символов
- **THEN** в имени метка `abc` или её первые 32 символа, остальные сегменты имени не меняются

#### Scenario: Составной эмодзи на границе длины
- **WHEN** метка — 31 буква и за ними эмодзи 👨‍👩‍👧
- **THEN** эмодзи входит в метку целиком, как 32-й символ, и не распадается на части

#### Scenario: Пробел на месте обрезки
- **WHEN** 32-й символ метки — пробел, а за ним идёт продолжение
- **THEN** метка обрезана до 31 символа без пробела в конце, имя не содержит ` .amostk.`

#### Scenario: Символы управления в метке
- **WHEN** подпись содержит перевод строки или символ U+202E
- **THEN** в имени файла этих символов нет

#### Scenario: Незнакомый вид при разборе
- **WHEN** разбирается имя `amostk.k-emoji.gif`
- **THEN** имя считается именем amo stickers, вид не определён

#### Scenario: Незнакомый параметр при разборе
- **WHEN** разбирается имя `amostk.k-sticker.s-lg.v-2.gif`
- **THEN** вид — стикер, параметры `s` и `v` возвращаются, имя не считается битым

#### Scenario: Отправка из «Избранного»
- **WHEN** пользователь отправляет из «Избранного» стикер Telegram с эмодзи 😀, чей пак уже удалён
- **THEN** файл называется `😀.amostk.k-sticker.gif` — так же, как при отправке из пака
