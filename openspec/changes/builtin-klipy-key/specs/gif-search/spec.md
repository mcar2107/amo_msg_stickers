## MODIFIED Requirements

### Requirement: Доступные источники
Система SHALL показывать источники по ключам: при своём ключе GIPHY — «GIPHY» (гифки) и «GIPHY стикеры», при своём ключе KLIPY или встроенном ключе KLIPY сборки — «KLIPY». Запросы к KLIPY MUST идти по своему ключу, если он задан, иначе — по встроенному. GIPHY MUST работать только по своему ключу. Если нет ни своих ключей, ни встроенного ключа KLIPY, режим «GIF» MUST показывать подсказку, кнопку, открывающую настройки, и ссылку на страницу доки о получении ключей (в новой вкладке, на языке интерфейса: из английского — английская страница, из русского — русская) вместо поиска и трендов; недавние GIF при этом остаются. Если источников больше одного, система MUST показывать переключатель между ними.

#### Scenario: Чистая установка со встроенным ключом
- **WHEN** в сборке есть встроенный ключ KLIPY, и пользователь без сохранённых ключей открывает режим «GIF»
- **THEN** показаны тренды KLIPY, поиск отдаёт выдачу KLIPY, переключателя источников нет

#### Scenario: Свой ключ KLIPY важнее встроенного
- **WHEN** в сборке есть встроенный ключ KLIPY, а в «Настройках» сохранён свой
- **THEN** запросы к KLIPY идут со своим ключом

#### Scenario: Ключ GIPHY при встроенном ключе
- **WHEN** в сборке есть встроенный ключ KLIPY, а в «Настройках» сохранён только ключ GIPHY
- **THEN** над выдачей есть переключатель «GIPHY», «GIPHY стикеры», «KLIPY»

#### Scenario: Нет ключей
- **WHEN** в сборке нет встроенного ключа KLIPY, и пользователь открывает режим «GIF» без сохранённых ключей
- **THEN** показан текст «Для поиска GIF нужен API-ключ GIPHY или KLIPY», кнопка «Открыть настройки» и ссылка на инструкцию; по нажатию кнопки открывается экран «Настройки»

#### Scenario: Инструкция по ключам
- **WHEN** пользователь без ключей нажимает ссылку на инструкцию в режиме «GIF»
- **THEN** в новой вкладке открывается страница доки о ключах GIF

#### Scenario: Инструкция по ключам на английском
- **WHEN** интерфейс на английском и пользователь без ключей нажимает ссылку на инструкцию в режиме «GIF»
- **THEN** в новой вкладке открывается английская страница доки о ключах GIF

#### Scenario: Оба ключа
- **WHEN** сохранены ключи GIPHY и KLIPY
- **THEN** над выдачей есть переключатель «GIPHY», «GIPHY стикеры», «KLIPY»

### Requirement: Атрибуция и фильтрация
Система MUST показывать атрибуцию выбранного источника («Powered by GIPHY» или «Powered by KLIPY») под выдачей, вне
прокручиваемой ленты: подпись видна без прокрутки при любой длине выдачи и не уезжает вместе с лентой. Запросы MUST
содержать фильтр контента: rating `pg-13` для GIPHY, contentfilter `medium` для KLIPY.

#### Scenario: Выдача GIPHY
- **WHEN** показана выдача GIPHY (GIF или стикеры)
- **THEN** под лентой есть подпись «Powered by GIPHY»

#### Scenario: Выдача KLIPY
- **WHEN** показана выдача KLIPY
- **THEN** под лентой есть подпись «Powered by KLIPY»

#### Scenario: Длинная выдача
- **WHEN** загружено несколько страниц выдачи и лента прокручена в начало или в середину
- **THEN** подпись источника видна на том же месте под лентой, без прокрутки к концу выдачи

#### Scenario: Смена источника
- **WHEN** пользователь переключает источник с GIPHY на KLIPY
- **THEN** подпись под лентой меняется на «Powered by KLIPY»

#### Scenario: Без ключей
- **WHEN** не задан ни один свой ключ источника, и в сборке нет встроенного ключа KLIPY
- **THEN** ленты и подписи нет, показана подсказка про API-ключ

### Requirement: Ошибки источника
При ошибке запроса система SHALL показать в статусе попапа текст ошибки с префиксом «GIF:». При ошибке подгрузки следующей страницы уже загруженная выдача MUST сохраняться. Если KLIPY отказывает встроенному ключу — HTTP 401, 403 или 404 (ключ отозван или недействителен) либо 429 (лимит), — ошибка MUST говорить, что встроенный ключ KLIPY недоступен, и предлагать указать свой ключ в «Настройках», а не показывать сырой `HTTP <код>`. Прочие ошибки встроенного ключа и любые ошибки своего ключа MUST показываться как есть.

#### Scenario: Неверный ключ
- **WHEN** ключ GIPHY недействителен и API возвращает 401 или 403
- **THEN** в статусе показано «GIF: HTTP 401 …» или «GIF: HTTP 403 …»

#### Scenario: Встроенный ключ отозван
- **WHEN** пользователь без своего ключа KLIPY открывает тренды KLIPY, а KLIPY отвечает на встроенный ключ HTTP 404 или 401
- **THEN** в статусе — ошибка, что встроенный ключ KLIPY недоступен, с предложением указать свой ключ в «Настройках»

#### Scenario: Свой ключ KLIPY не принят
- **WHEN** у пользователя свой ключ KLIPY, и KLIPY отвечает на него HTTP 404
- **THEN** в статусе показано «GIF: HTTP 404 …», без слов о встроенном ключе

#### Scenario: Сбой сети на встроенном ключе
- **WHEN** запрос KLIPY со встроенным ключом обрывается сетевой ошибкой или отвечает HTTP 500
- **THEN** в статусе — текст этой ошибки как есть
